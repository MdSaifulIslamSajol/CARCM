# CARCM: Context-Aware Rice Drought-Response Classifier

CARCM predicts whether a rice gene is up- or down-regulated under drought
stress from its promoter sequence **and** its biological context (rice
variety, tissue, and developmental stage), combined through a gated attention
fusion mechanism. CARCM is trained on 44,502 gene expression records spanning
13 rice varieties, 8 tissues, and 6 developmental stages, and outperforms 12
classical/deep-learning baselines and 8 DNA foundation models.

## Dataset

The main dataset is
[`data_preprocess/RiceMetaSys_Drought_merged_all_excels_6.csv`](data_preprocess/RiceMetaSys_Drought_merged_all_excels_6.csv)
— 44,502 rice gene records merged from RiceMetaSys drought-response
expression data, each annotated with its promoter sequence, rice variety,
tissue, developmental stage, and up/down-regulation label.

[`rice_positional_pipeline.py`](rice_positional_pipeline.py) extracts ~400+
positional cis-regulatory-motif features (binned motif counts, relative
positions, co-occurrence patterns, density gradients, etc.) from the promoter
sequences and writes the model-ready, stratified train/dev/test splits to
[`output/`](output/) (`train.csv`, `dev.csv`, `test.csv`, `feature_groups.json`,
`feature_names.txt`). Pre-generated splits are already included in `output/`,
so you can skip straight to training/evaluation below.

## Setup

```bash
conda env create -f environment.yml
conda activate carcm
```

or with pip:

```bash
pip install -r requirements.txt
```

## Quick demo: running `rice_classifier_v7b.py`

`rice_classifier_v7b.py` loads `output/{train,dev,test}.csv`, trains an
ensemble of `ContextEnhancedGatedFusionV5` (CARCM) models, evaluates them, and
writes metrics/figures to `models_carcm/<run_name>/`.

A few things to check before running:
- The script pins `CUDA_VISIBLE_DEVICES=5` ([rice_classifier_v7b.py:24](rice_classifier_v7b.py#L24)) — change this to a GPU available on your machine (or remove the line to use CPU/auto-detect).
- Checkpoints are written to `CHECKPOINT_DIR` ([rice_classifier_v7b.py:107](rice_classifier_v7b.py#L107)), which defaults to an external mount path — update it if that path doesn't exist on your system.

**Fast smoke test** (1 seed, few epochs, ~minutes):

```bash
conda activate carcm
python rice_classifier_v7b.py \
    --num_seeds 1 \
    --num_epochs 10 \
    --patience 5 \
    --run_name quick_demo
```

Results, plots, and `console_output.txt` will be written to
`models_carcm/quick_demo/`.

**Full reproduction of the best reported configuration** (10 seeds, 150
epochs):

```bash
./run_carcm_full.sh
```

This runs `rice_positional_pipeline.py` followed by
`rice_classifier_v7b.py --learning_rate 1e-3 --hidden_dim 128 --dropout 0.4 --batch_size 128 --num_seeds 10 --run_name best`.
