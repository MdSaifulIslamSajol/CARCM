CONCLUSION
===========================================================================

  The context permutation test is highly significant (p < 0.001).

  When context one-hots are randomly shuffled at inference time
  (destroying the true variety/tissue/stage pairing while preserving
  the marginal distribution), AUC drops from 0.8522 to
  0.5420 (ΔAUC = +0.3102).

  This confirms that context features carry REAL biological signal
  at inference time. The model is not merely memorising motif patterns;
  it actively uses the biological context (variety, tissue, stage)
  to modulate its predictions.

  The effect size (Cohen's d = 39.18) indicates a
  LARGE effect — context is a major contributor to prediction quality.

  Distinct from ablation row #6 (permuted-label training):
    - Row #6 tests whether the model needs real context to LEARN.
    - This test measures how much context matters at INFERENCE.
    Both are reported for completeness.
